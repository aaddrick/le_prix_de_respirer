TaxCalculator examples

Calling js/taxCalculator.js on its own, 2026 tax year. The full calculator is at index.html.

Usage

import { TaxCalculator } from './js/taxCalculator.js'; const t = new TaxCalculator(); const r = t.calculate({ employmentIncome: 75000, province: 'on', otherDeductions: 0 }); r.totals.takeHome; // cash after income tax and payroll r.federal.net; // federal tax r.provincial.net; // provincial or territorial tax r.payroll.total; // CPP/QPP + CPP2/QPP2 + EI (+ QPIP in Quebec)
